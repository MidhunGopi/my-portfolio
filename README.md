# Midhun Gopi - Portfolio Website

A professional portfolio website showcasing my skills, experience, and background as a Backend Developer.

## 🚀 Live Demo

Open `index.html` in your browser to view the portfolio.

## 📋 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Sections Include**:
  - Hero section with introduction
  - About Me section
  - Technical Skills (Python, Django, JavaScript, React.js, etc.)
  - Work Experience timeline
  - Education background
  - Contact information with LinkedIn and GitHub links

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Variables and Flexbox/Grid)
- Vanilla JavaScript
- Google Fonts (Inter)
