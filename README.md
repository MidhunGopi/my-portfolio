# Midhun Gopi - Portfolio Website

A simple, responsive portfolio website for Midhun Gopi.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Sections**:
  - Hero section with introduction
  - About section
  - Skills section with technology cards
  - Projects section showcasing work
  - Contact section with form and social links
- **Interactive Navigation**: Smooth scrolling and mobile-friendly hamburger menu
- **Contact Form**: Simple form for visitors to reach out

## Technologies Used

- HTML5
- CSS3 (with CSS Grid, Flexbox, and CSS animations)
- Vanilla JavaScript
- Google Fonts (Poppins)

## Getting Started

Simply open `index.html` in your browser to view the portfolio.

## File Structure

```
my-portfolio/
├── index.html          # Main HTML file
├── css/
│   └── styles.css      # Stylesheet
├── js/
│   └── main.js         # JavaScript functionality
└── README.md           # This file
```

## Customization

To customize this portfolio for your own use:

1. Edit `index.html` to update personal information, skills, and projects
2. Modify `css/styles.css` to change colors, fonts, or layout
3. Update `js/main.js` to add or modify interactive features
